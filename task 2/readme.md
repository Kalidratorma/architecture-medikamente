# Task2 — Диаграмма контейнеров (C4) и описание целевой архитектуры (MVP, 1 год)

## Диаграмма
Файл: `project10-landscape.drawio.xml` — контейнерная диаграмма системы «Медикаменте» (MVP, горизонт 1 год).

## Целевые принципы
- **Кластер и масштабируемость:** микросервисы, stateless-ядро, горизонтальное масштабирование.
- **Privacy by Design:** минимизация данных, тегирование (Data Catalog), маскирование в потоках (NiFi), удаление ключа = удаление данных (KMS).
- **RBAC/ABAC:** Keycloak + AD, политика доступа на основе ролей и атрибутов (тегов).
- **Шифрование:** TLS 1.2+, TDE/row‑level security в БД, шифрование сканов в S3 (SSE‑KMS).
- **Аудит и мониторинг:** централизованные логи, события безопасности, алертинг.
- **Интеграции по контрактам:** HL7 для лаборатории, PCI DSS для платежей, API gateway с WAF.

## Контейнеры (основные)
- **Web App / Mobile App ** — клиентские приложения.
- **API Gateway (Kong)** — TLS/mTLS, rate limit, WAF, маршрутизация.
- **Сервисы домена:** расписание/записи, пациенты/медкарты, платежи, CRM, уведомления, интеграция с лабораторией.
- **Платформа:** Keycloak+AD (SSO, RBAC), Apache NiFi (контроль потоков ПДн), Kafka (events).
- **Хранилища:** PostgreSQL (OLTP), Redis (кэш/токены), Object Storage S3 (сканы), KMS (ключи).
- **Внешние системы:** 1С (server mode), Банк Эквайер, Лаборатория

## Потоки и меры защиты (выдержка)
- Клиенты → API Gateway: **HTTPS/TLS**, OIDC (Keycloak).
- Внутренние сервисы ↔ Gateway: **mTLS**, rate limiting.
- Пациенты/медкарты → PostgreSQL: **TDE + RLS**, шифрование ключами из **KMS**.
- Сканы → **S3 (SSE‑KMS)**, доступ по временным токенам.
- Лаборатория: **HL7** по TLS, контракты скрывают избыточные категории (anti‑IDOR).
- Платежи: **PCI DSS**, токенизация карт, связь с ККТ по TCP/IP.
- Потоки ПДн: **Apache NiFi** — маскирование/фильтрация.

## MVP и развитие
- **MVP:** онлайн‑запись, уведомления, просмотр своих данных в ЛК/мобиле; ресепшен видит и подтверждает записи.
- **1 год:** полностью автоматизированная запись, аудит доступа, аномалии поведения.
