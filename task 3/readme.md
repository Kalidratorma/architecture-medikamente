# Классификация данных и меры защиты

| Данные | В чём необходимость защиты | Инструменты защиты |
|--------|-----------------------------|---------------------|
| **Персональные данные (PII)** — ФИО, паспортные данные, телефон, email | Требование ФЗ‑152, GDPR; риск утечки персональных данных и штрафов; доверие клиентов | Шифрование в хранении (DB TDE), шифрование при передаче (TLS), RBAC/ABAC через Keycloak+AD, токенизация, управление ключами через KMS/Vault |
| **Медицинские данные (PHI)** — диагнозы, результаты анализов, медицинские карты (Excel, сканы PDF/JPG) | HIPAA/GDPR; риск дискриминации и утраты доверия пациентов | Объектное хранилище S3 с SSE‑KMS, тегирование и маскирование через NiFi, контроль доступа по тегам (Data Catalog), шифрование in transit (TLS), аудит доступа |
| **Платёжные данные** — транзакции, чеки ККМ, данные карт | Требования PCI DSS; риск мошенничества и штрафов | Интеграция через платёжный шлюз, токенизация, TLS/mTLS, хранение токенов в Redis, разделение ролей (кассир, бухгалтер) |
| **Внутренние бизнес‑данные** — Excel‑отчёты, бухгалтерия 1С, торговля и склад | Конфиденциальная информация; риск конкурентных утечек | Шифрование БД (TDE), разграничение доступа (RBAC), контроль через NiFi, аудит изменений |
| **Операционные логи / Журналы аудита** — логи доступа, действия админов | Требования ФЗ‑152, GDPR, HIPAA; расследование инцидентов | Централизованный сбор (ELK/Prometheus), хранение с неизменяемостью (WORM), мониторинг и алерты |
| **Производные / аналитические данные** — агрегированные и обезличенные данные для DWH/BI/ML | Использование для аналитики и прогнозирования без риска раскрытия ПДн | Анонимизация, деперсонализация, агрегация в DWH, маскирование чувствительных полей, контроль выгрузок |

---

## Итоги

- Все персональные и медицинские данные защищаются по принципу **Privacy by Design**.  
- Используются механизмы **шифрования, токенизации, анонимизации и RBAC/ABAC**.  
- Управление ключами — через **KMS/Vault**.  
- Интеграции с внешними системами осуществляются только по **TLS/mTLS** с контрактным API.
